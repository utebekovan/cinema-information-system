# Cinema Information System Requirements

## Purpose
The purpose of the system is to automate cinema services.

## Main Users
1. Customer
2. Administrator
3. Cinema Manager

## Main Functions
- View movies
- View movie schedules
- Choose seats
- Book tickets
- Manage movies
- Manage schedules

## Main Components
- User interface
- Authentication module
- Booking module
- Movie management module
- Database
- Notification module
